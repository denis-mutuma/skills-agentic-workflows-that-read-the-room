## Recent updates

- **Stacked pull requests are generally available.** Break large changes into smaller pull requests that are reviewed independently and merged together. Rebase stack preserves approvals for unchanged code, and the `gh stack` GitHub CLI extension now supports Git worktrees. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/).
- **Local sandboxing for GitHub Copilot is generally available.** Copilot CLI, the Copilot app, and VS Code sessions using Agent Host can run Copilot-initiated commands with restricted filesystem, network, and credential access. It is included at no additional cost. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/).
